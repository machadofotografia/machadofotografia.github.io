# Regras do Repositório (Git & Commits)

## Mensagens de Commit

Sempre que gerar, sugerir ou criar mensagens de commit (inclusive via botão de gerar mensagem na interface do Git / IDE):
- A mensagem **DEVE ser obrigatoriamente em português**.
- Siga o padrão **Conventional Commits** com **Gitmoji** (emoji no início).
- Formato: `<emoji> <tipo>(<escopo>): <descrição em português>`
  - Exemplo: `🐛 fix(menu): corrige menu colapsável no celular`
  - Exemplo: `✨ feat(contato): adiciona envio via Formspree com feedback na página`
  - Exemplo: `💄 style(galeria): ajusta alinhamento e centralização do masonry`
- Título conciso, verbo no indicativo/imperativo, sem ponto final no título.
- Se houver corpo/descrição longa, detalhe as alterações em lista com marcadores (`- `) em português.
